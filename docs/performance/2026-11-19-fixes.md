# 修复与复测（2026-11-19）

## 改动

- Disk：上传去重和永久删除在完整元数据事务范围内恢复 MySQL 1213 死锁。首次失败后最多重试六次，退避为 2、4、8、16、32、64 ms。失败事务先析构回滚并归还连接，再重新检查配额、目录与引用。锁超时、网络异常及提交结果不确定不在重试范围内。
- 文件正文不重传；存储 RPC 不放入该重试循环，永久删除的对象清理仍在提交成功后执行。
- gin_cpp：提前拒绝未完成的请求，在响应写完成后限时消费迟到正文，采用 1 秒宽限期和 1 MiB 排空阈值，随后关闭连接。拒绝后的连接不再复用，避免带未读数据立即关闭导致 TCP 重置，同时限制连接占用。
- 新增重试策略测试，验证事务展开顺序、重试上限、锁超时和其他错误不重试；运行时测试增加 200 次拒绝后继续发送正文的时序回归。
