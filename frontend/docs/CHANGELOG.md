# 前端改动记录

从 2026-10-13 开始记录本项目的逐轮改动。以后每次完成一轮修改，在此文件新增一节，写明用户可感知的变化、Git 状态与验证范围。本文不代替 Git 提交历史；“未提交”表示仍在本地工作区，尚未部署。

## 2026-10-13｜可调工作区与界面设置（未提交）

- 在最左侧导航底部加入“设置”入口，打开应用内界面设置；提供目录栏、详情栏宽度滑块和恢复默认。
- 目录栏、详情栏新增可拖动分隔线，也可用键盘方向键、Home／End 调宽；拖动结束后将宽度保存在当前浏览器。设置窗口关闭后焦点回到入口。
- 窄窗口按需收窄或隐藏面板，为文件区预留至少约 400 px；保存的偏好宽度不因临时收窄而被覆盖。
- 参考 HanaAgent 的 [`use-sidebar-resize.ts`](https://github.com/liliMozi/openhanako/blob/main/desktop/src/react/hooks/use-sidebar-resize.ts)、[`SidebarLayout.tsx`](https://github.com/liliMozi/openhanako/blob/main/desktop/src/react/components/SidebarLayout.tsx) 和 [`SettingsModalShell.tsx`](https://github.com/liliMozi/openhanako/blob/main/desktop/src/react/components/SettingsModalShell.tsx) 的拖拽约束、持久化与设置窗口交互；没有移植其 Electron 专用配置。
- 验证：`npm run build`、`git diff --check`、边界和存储脚本通过；本地浏览器用模拟数据测试了设置入口、滑块、拖动、最小文件区、恢复默认及焦点返回。Go 后端未启动，尚未进行真实数据的端到端验证。

## 2026-10-13｜目录与文件操作的键盘路径（未提交）

- 侧边目录支持 Enter／空格打开，方向键展开和收起；焦点与选中状态有可见、可朗读的反馈。
- 操作菜单打开后聚焦首个可用项，支持上下方向键、Home／End，Escape 或 Tab 可返回原操作入口。
- 移动弹窗打开后聚焦内部按钮，并限制 Tab 焦点离开弹窗；移动期间不再允许点遮罩关闭或改选目标。
- 验证：`npm run build`、`git diff --check`、目录及移动弹窗的静态结构检查通过。Go 后端未启动，未做实际浏览器键盘操作验收。

## 2026-10-13｜列表加载、错误与重试（未提交）

- 文件夹、搜索和回收站分别显示加载中、加载失败与真实空结果；失败时提供“重试加载”。
- 切换文件夹、分页或排序时清除旧列表，避免在新目录标题下误显示旧目录文件。
- 初始化加载完成前保持加载提示；首次加载失败也可重试。
- 验证：`npm run build`、`git diff --check`、列表加载／失败／空状态的静态渲染检查通过。尚未连接 Go 后端做浏览器端到端验证。

## 2026-10-13｜窄屏与文件操作可发现性（未提交）

- 窄屏首次进入时收起详情栏；手动打开后可用关闭按钮、遮罩或 Escape 返回文件区。
- 文件行增加勾选框，多选后可“全选本页”；长文件名可通过悬停标题查看。
- 文件夹空状态提供直接上传入口；搜索空状态给出下一步提示。
- 验证：`npm run build`、窄屏默认状态、列表勾选及空状态的静态渲染检查通过。
